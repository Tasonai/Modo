# Руководство по внешним наборам иконок (Icon Sets) в Modo

Modo v1.5.0 поддерживает подключение внешних наборов готовых иконок (Icon Sets / Icon Packs) из интернета или локальных архивов. В отличие от пресетов стилизации (форм и цветов), **Icon Sets** содержат конкретные авторские изображения для приложений (сопоставляемые по Bundle Identifier), которые затем органично встраиваются в генеративный движок Modo (формы Squircle/Circle/Hexagon/Pebble, монохром, подложки и тени).

---

## 1. Структура архива набора (`.zip`)

Любой набор иконок представляет собой обычный ZIP-архив без вложенных абсолютных путей или симлинков со следующей структурой:

```
my-cool-set.zip
├── manifest.json
└── icons/
    ├── chrome.png
    ├── vscode.png
    ├── telegram.png
    └── ...
```

### Спецификация `manifest.json`

```json
{
  "format": "modo-icon-set",
  "version": 1,
  "id": "minimal-dark",
  "name": "Minimal Dark Icons",
  "author": "Atoma Studio",
  "license": "CC-BY-4.0",
  "icons": [
    {
      "bundleID": "com.google.Chrome",
      "file": "icons/chrome.png"
    },
    {
      "bundleID": "com.microsoft.VSCode",
      "file": "icons/vscode.png"
    },
    {
      "bundleID": "ru.keepcoder.Telegram",
      "file": "icons/telegram.png"
    }
  ]
}
```

### Требования безопасности и валидации
- **Идентификатор (`id`)**: только латинские строчные буквы, цифры, дефис и подчеркивание (`^[a-z0-9][a-z0-9_-]{1,63}$`).
- **Пути (`file`)**: относительные пути без перехода на уровень выше (`..`) и без абсолютных префиксов (`/`).
- **Формат изображений**: валидный PNG с максимальным разрешением до 2048×2048 px и размером одного файла не более 6 МБ.
- **Размер архива**: до 80 МБ распакованного содержимого и не более 50 000 иконок в одном наборе.
- Символические ссылки (`symlinks`) строго запрещены и отбрасываются при распаковке.

## 2. Онлайн-каталог (`catalog.json`)

Вы можете разместить свой каталог на GitHub Pages, GitHub Releases или любом HTTPS-хостинге.

### Спецификация `catalog.json`

```json
{
  "format": "modo-icon-catalog",
  "version": 1,
  "sets": [
    {
      "id": "minimal-dark",
      "name": "Minimal Dark Icons",
      "author": "Atoma Studio",
      "license": "CC-BY-4.0",
      "version": "1.0.0",
      "url": "https://example.com/sets/minimal-dark.zip",
      "sha256": "4b227777d4dd1fc61c6f884f48641d02b4d121d3fd328cb08b5531fcacdabf8a",
      "sizeBytes": 14250000,
      "iconCount": 420
    }
  ]
}
```

- **Хэш (`sha256`)**: 64-символьный SHA-256 дайджест ZIP-архива. Modo строго проверяет соответствие хэша перед распаковкой.

---

## 3. Использование в Modo

### Способ 1: Браузер онлайн-каталогов
1. Откройте Modo и в левой боковой панели в секции **Icon Sets** нажмите кнопку **«Get Icon Sets…»**.
2. В появившемся окне отображается список наборов из каталога с количеством иконок, автором и лицензией.
3. Нажмите **«Install»** напротив нужного набора. Modo проверит хэш и безопасно установит набор.

### Способ 2: Ручная установка из ZIP
В окне браузера каталогов нажмите кнопку **«Install from ZIP…»** и выберите локальный `.zip` архив.

### Настройка URL каталога
В окне **Settings** (Настройки) в поле **Icon Set Catalog URL** можно указать любой собственный адрес каталога (по умолчанию используется официальный репозиторий каталогов сообщества).
