# Homebrew Tap for Modo

Official Homebrew Tap for **Modo** — Native Adaptive Icon Studio for macOS & Windows by Atoma.

## Installation

Install Modo directly via Homebrew Cask:

```bash
brew install --cask tasonai/tap/modo
```

Or tap this repository first:

```bash
brew tap tasonai/tap
brew install --cask modo
```

## Updates

```bash
brew upgrade --cask modo
```
