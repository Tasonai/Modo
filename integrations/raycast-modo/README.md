# Modo Raycast Extension

Instantly style any macOS application or Finder folder with adaptive Material You, Squircle, or Hexagon shapes directly from [Raycast](https://raycast.com).

## Prerequisites
- Modo for macOS installed
- `modo` CLI available in `~/.local/bin/modo` or `/usr/local/bin/modo`

## Commands
- **Style Application Icon**: Browse and search installed apps, choose a shape (Squircle, Circle, Hexagon, etc.), and apply in 1 click.
- **Style Finder Folder**: Tint Finder folders with custom color presets (Sunset, Emerald, Ocean, Graphite) and embossed glyphs.
- **Restore Original Icon**: Revert custom icons back to the original macOS defaults.

## Development & Installation
```bash
cd integrations/raycast-modo
npm install
npm run dev
```
